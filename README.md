# 心理史学 · 谢顿计划

30 回合的合成银河策略游戏。你扮演哈里·谢顿，在帝国衰落中回应急电、照看星区，把知识送往基地。纯前端运行，没有后端、账号或外部 AI API。

[在线体验](https://origintime9-crypto.github.io/psychohistory-demo/)

## 本地运行

```powershell
npm ci
npm run dev
```

打开终端显示的本地地址，默认 `http://127.0.0.1:5173`。设置种子与星区规模后，先完成三步入门，可以亲自重复一个练习推演。正式游戏每回合：读急电并选择回应 → 选择一张干预卡 → 在星图指定目标 → 查看直接效果与长期代价 → 执行并推进十年。共 30 回合、300 年，分为衰落、裂变、保留知识三个阶段。

八类急电包括粮运、总督抗命、知识转移、自治请愿、融资、教育争执、难民与幕后协调。出现时机、类别与目标会随种子和局势变化；选择会改变实际资源和状态，谈判与融资含成功、失败分支。事件和卡牌共享影响力。结果画面区分命令的直接效果与十年后的实际恢复、动荡、叛乱和独立。

顶部“大数定律”可查看统计对照。每回合和待执行的事件回应都会自动保存在当前浏览器；刷新可继续，结局也可恢复。新推演会替换当前存档。结束后可导出 JSON 报告，包含种子、参数、事件回应、卡牌、历史与模型指纹。

```powershell
npm test
npm run format:check
npm run build
npm run sim -- --policy=all --games=100 --seed-prefix=v3-final-heldout
npm run study:cards
npm run validate:model
```

同一种子、参数和同一行动序列可复现世界、手牌、急电与现实路径。预测、现实与校准随机流分离；所有分支保持现实抽样预算相同。生产构建在 `dist`；`npm run preview` 可预览。图表在本地渲染，不需网络资源。

成绩使用 `F_eff = 0.1 + 0.9F`、`Q = √(F_eff × S)`，S 为最后三回合平均稳定占比。维稳有基础分，基地收益递减并依赖稳定与端点星；满进度后仍可提供知识援助。减税仅持续四回合，精英安置影响邻区，影响力通常每回合恢复一点。

预测按当前事件回应与卡牌执行，之后按兵不动、暂缓后续事件。未来急电通过独立流采样；预测器不读取现实未来的事件日历，也不知道可选的“骡”。“骡”在随机回合出现，可能击穿事前预测区间。卡面用 32 条配对路径粗估，选中后用 96 条精算；目标热力图是共同冲击为零的单步示范，定向候选经过筛选，均不构成最优保证。

PITF 和结构人口理论仅提供定性启发；数值是游戏参数，不是实证系数。独立对照关闭邻区传染、共同冲击、财政反馈与跨区事件。合成校准不证明现实社会的预测能力，单局覆盖率也不足以检验校准。自动完整游玩验证与人类体验评价不同，目前没有“真人十分钟一局”的实测结论。

## 网站部署

GitHub Pages 使用 `.github/workflows/deploy.yml` 自动部署。向 `main` 推送后，工作流安装锁定版本的依赖、检查格式、运行引擎与事件回归测试、构建并发布 `dist`。构建从 Pages 读取子目录路径，星图、图表与预测 Worker 使用同一资源前缀。GitHub Desktop 可直接提交并推送本项目。

原始计划 PDF、本机截图、浏览器记录、验收数据、部署凭据与临时文件均保留在本机，不进入公开仓库。完整本地审阅和验收记录位于 `docs/` 与 `reports/`；批量模拟和模型验证会在本地产生 `reports/`。
